## 🧠 Overview

Alien Skin Exposure is a film emulation plug-in: it recreates colour and black-and-white stocks frame by frame, including grain, halation, lens blur and vignetting as adjustable layers rather than a fixed filter.

Published by Exposure Software. Category: Film emulation for photos.

The archive in this repository contains the plug-in suite itself plus the integration files for Adobe Photoshop CC 2019 or newer, Adobe Lightroom Classic, Affinity Photo.

## 🚀 Key Features

| Feature | Description |
| --- | --- |
| 🎞️ Film Stocks | Hundreds of colour and black-and-white emulations built from scanned negatives. |
| 🌾 Grain Engine | Grain size, roughness and shadow/highlight balance are controlled separately. |
| 🌟 Halation and Bloom | Adds the red glow around highlights that film shows on bright edges. |
| 🔭 Lens and Focus | Simulates vintage lenses: vignette, soft focus and chromatic fringing. |
| 🧱 Layer Stack | Effects are stacked and reordered, each with its own opacity and mask. |
| 🎨 Presets per Camera | Stocks are matched to the source camera profile for a closer starting point. |
| 🖼️ Batch Export | Applies one look to a folder of images with a naming pattern. |

## Additional Information for Windows Users

The plug-in suite registers itself in Adobe Photoshop CC 2019 or newer, Adobe Lightroom Classic during installation, so the host version matters more than the Windows build: update the host application before adding Alien Skin Exposure.

Settings created in Alien Skin Exposure are stored in the plug-in's own preset folder, so a reinstall keeps user presets and replaces only program files.
